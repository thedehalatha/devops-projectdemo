# Selenium Automation Testing with Python

## About
This repository contains my beginner-level exploration of Selenium WebDriver using Python.

I implemented a simple automation test case that:
- Opens Google Chrome automatically.
- Navigates to Google.
- Finds the Google search box.
- Enters "Selenium WebDriver".
- Submits the search.
- Displays the page title.
- Closes the browser.

## Technologies Used
- Python 3
- Selenium WebDriver
- Google Chrome
- VS Code

## Installation

Install Selenium:

```bash
pip install selenium
```

## Run the Program

```bash
python selenium_test.py
```

## What I Learned
- Installing Selenium.
- Using Selenium WebDriver.
- Locating web elements using By.NAME.
- Automating browser actions.
- Using send_keys(), submit(), and driver.quit().
